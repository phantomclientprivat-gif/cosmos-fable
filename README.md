# Cosmos Fable

A modern **Bento Glass** desktop tracker built with Python and Flet for daily nutrition (macros), adaptive workout cycles, and focused study notes.

## Quick Start

### Linux (One-Command Auto Setup)
```bash
git clone https://github.com/phantomclientprivat-gif/cosmos-fable.git && cd cosmos-fable && ./setup.sh
```

### Windows / macOS (Manual Setup)
```bash
git clone https://github.com/phantomclientprivat-gif/cosmos-fable.git
cd cosmos-fable
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Download for Android

Download **cosmos fable.apk** directly from the [Releases](https://github.com) page.
